# 와이펫 세이프 — 원본 디자인 기반 재구성

HTML, CSS, JavaScript. npm 설치·빌드 없이 실행합니다.

## 파일
- `dist/index.html`: 업로드된 원본 HTML의 디자인·문구·스타일을 유지한 메인 페이지. 사용자 정의 JavaScript는 HTML 안에 포함.
- `dist/assets/`: 제공된 이미지 및 CSS.
- `dist/scanner.html`: SC400 BLE 연결·알림 수신·원시 기록 JSON 다운로드.
- `.github/workflows/pages.yml`: main push 시 GitHub Pages 배포.

## GitHub 배포
1. GitHub에 `ypetsafe` 새 저장소를 만들고 이 폴더의 내용을 업로드합니다. dist 폴더 자체를 포함합니다.
2. Settings → Pages → Source를 GitHub Actions로 선택합니다.
3. main 브랜치에 push하면 배포됩니다. Actions에서 성공 여부를 확인합니다.

## 현재 동작과 한계
- 제품 안내·FAQ·이미지·PC/모바일 화면·페이지 내 이동을 복원했습니다.
- 기존 파트너 프로그램 버튼은 새 스캐너 테스트 페이지로 연결됩니다.
- 구매·샘플 버튼은 도입 문의로 이동합니다. 결제 기능은 포함하지 않습니다.
- 문의 제출은 이메일 앱에 내용을 작성합니다. 사용자가 이메일을 발송해야 접수됩니다. 원본 업체 서버로 폼을 직접 전송하지 않습니다.
- 원본에 있던 외부 분석/광고 스크립트, 브라우저 확장 삽입 코드, 원본 플랫폼 실행 코드는 제외했습니다.
- 로고·제품 사진·디자인·문구는 제공받은 자료를 사용합니다. 일부 배경 이미지와 웹폰트는 원본 CDN을 참조하므로 인터넷이 필요합니다.
- 첫 화면은 원본의 배경 사진을 사용합니다. 원본 YouTube 자동재생 배경은 브라우저 제한 및 검은 화면 문제 때문에 제외했습니다.
- BLE 서비스 UUID는 대화에서 확인된 `3a95e1b9-d1a2-4876-8335-02108039b3a2`를 사용합니다. 알림 지원 characteristic을 자동 조회합니다. 기기에 명령을 쓰지 않습니다.
- 실제 패킷 전체가 파일로 제공되지 않았으므로 칩 번호·온도 자동 해석은 구현했다고 주장하지 않습니다. 먼저 실물에서 JSON 로그를 저장해 변환 규칙을 검증해야 합니다.
- 회원가입, 서버 저장, 개체별 기록 공유는 포함하지 않습니다.
- 실물 SC400 연결은 갤럭시 Chrome에서 검증해야 합니다. HTTPS가 필요합니다.

로컬 확인: `python -m http.server 8000 --directory dist`
